# Task 1

For Assignment 3, I decided to continue with my Car Mods visualization from Assignment 2, which consists of a sunburst diagram and the mod-rate matrix. The static visualization shows total counts of modified vehicles by range, while the matrix shows mod rates by class and year range. It displays all three vehicle classes simultaneously, while the interactive version adds a dropdown menu that allows users to filter by Economy, Luxury, or Performance. Selecting a class updates both the sunburst and the matrix to display only vehicles belonging to that class.

The main reason I chose filtering was to make it easier to distinguish between the total number of modified vehicles and the percentage of vehicles modified within a particular category. This was something I noticed in Assignment 2, where a category having more modified cars didn't necessarily mean it had a higher modification rate. By filtering out the other classes, users can focus on one class and compare its modification rates across different year ranges without having to look through the entire matrix.

I expect this to reduce the time needed to identify these differences, although I'm not entirely sure it will. The static version already displays all the information at once, which could actually make comparisons between classes easier since users don't have to switch between filters. That's something I want to investigate during the evaluation.
